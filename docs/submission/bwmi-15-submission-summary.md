# India Import Preflight — submission summary

Word count: 187

India Import Preflight helps an Indian MSME decide whether to place a connected-electronics order before compliance gaps become clearance delays.

The public, no-login journey supports three independently verified scenarios: a new retail Wi-Fi router, over-ear Bluetooth headphones, and an indoor Wi-Fi/IP camera. For each exact boundary, deterministic TypeScript checks required facts and evidence, matches an admitted HS mapping, and returns one outcome: Ready within checked scope, Blocked, or Needs verification.

The report shows why the outcome was reached, official source pinpoints and review dates, evidence used and missing, ordered actions with owners and official destinations, and either a decimal-safe customs-value and duty estimate or the exact reason numeric cost is withheld. A blocker is shown only when an admitted official rule conditions or prevents Customs clearance.

Everything outside the supported catalog uses Other product. That path preserves universal shipment facts for a licensed Customs Broker but never guesses classification, rules, documents, rates, or cost.

One hash-pinned synthetic router pro-forma-invoice PDF can populate editable facts after explicit confirmation. Images, certificates, additional documents, other-product extraction, live government filing, approval, accounts, and saved cases are not presented as working behavior.
